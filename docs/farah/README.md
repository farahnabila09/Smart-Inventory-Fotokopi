## Use Case Description for Manage Dashboard & Report
<img width="645" height="184" alt="image" src="https://github.com/user-attachments/assets/9bad7a91-e044-4dcc-a519-660c04111ba7" />

- Use Case ID : UC016
- Author : Farah 
- Use Case Name : View Stock Dashboard 
- Written Date : 13/5/2026
- Actor : Admin, Staff 
- Description : A function that allows users to view dashboard information related to stock overview, low stock alerts, overstock alerts and inventory summaries within the Smart Inventory System. 
- Pre-condition : User must be logged into the system
- Basic Steps
- 1. The users log into the system. 
- 2. Navigate to the “Dashboard” section. 
- 3. The system retrieves inventory dashboard data.
- 4. The system displays stock overview, low stock alerts, overstock alerts and inventory summaries. 

- Alternate Steps : If there are no inventory data available, the system displays an appropriate message to the user. 
- Exception : If the system fails to retrieve dashboard information then an error message will be displayed. 
- Post Condition : Dashboard information is displayed successfully.
- Business Validation/Rules : Dashboard information should only be accessible to authorized users based on their assigned roles.
